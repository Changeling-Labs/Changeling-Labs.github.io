Privacy Policy

Last updated 9 November 2026 · covers changelinglabs.com and the apps hosted under it.

The short version

  • — No accounts, no advertising, and no cookies.
  • — Apps keep your data in your own browser. The only exceptions are the three you explicitly opt into: Pulse cloud sync, About Time outings and Done game rooms.
  • — Pulse sync is opt-in, uses a passwordless email sign-in, and stores only your own records.
  • — About Time has no sign-in: it shares only the display name, battery level and “ready” state you enter for an outing, plus a push subscription if you turn alerts on.
  • — Done has no sign-in: it shares only the display name, emoji, round number and “done” state you enter for a game room, plus a push subscription if you turn alerts on.
  • — Cookieless, aggregate analytics on the hub and Pulse: no persistent IDs, no cross-site profiles, and it cannot see your logged data.

What this covers

The hub at changelinglabs.com and the applications linked from it: Pulse (/pulse/), Bible Tracker (/bible-tracker/), About Time (/about-time/), Done (/done/) and the Car Wash demo (/car-wash/). Each one is open source in its own public repository, so every claim below can be checked against the code rather than taken on trust.

What is stored, and where

The hub page stores nothing: no cookies, no identifiers, no local storage — it is static HTML and CSS. The applications that hold progress keep it in your browser's own storage, which never leaves your device and is not visible to this site or to anyone else. The exceptions are features you choose to use: Pulse cloud sync, About Time and Done, whose whole purpose is to share a small amount of state with the other people in your outing or game room. The only measurement request is the aggregate pageview described below; it never sees your app data.

App What it keeps Where
Pulse Logged workouts, exercises, fuel, recovery and preferences IndexedDB; Supabase only if you enable cloud sync
Bible Tracker Reading progress, read history, notes, stars localStorage
About Time Display name, chosen emoji, social-battery level, “ready” state, and a push subscription if alerts are on Supabase (shared with the people in your outing); device storage keeps only which outing you are in
Done Display name, chosen emoji, current round, “done” state, and a push subscription if alerts are on Supabase (shared with the players in your room); device storage keeps only which room you are in
Car Wash demo Demonstration member records (synthetic, not real people) IndexedDB

Browser storage belongs to whoever served the page, so clearing site data for this site deletes it permanently. Each app has an Export button for a portable JSON backup; use it before clearing anything. Note too that the storage is scoped to the address you opened — the same app served from a different address (a local file, a local server, or the published site) has its own separate store, and those stores do not merge automatically. The opt-in exceptions are Pulse cloud sync (signing in on two devices shares one history), About Time (everyone who joins the same outing code sees the same state) and Done (everyone in the same game room sees the round and who is done).

Third parties your browser talks to

Loading any web page means the servers hosting it and its assets see your IP address and standard request headers. This site is no exception, so here is the complete list:

  • GitHub Pages — hosting

    Serves every page here, so GitHub necessarily sees the requests and keeps whatever logs its own policy allows. This site keeps no logs of its own.

  • GoatCounter — cookieless analytics

    The hub and Pulse load GoatCounter on the production domain only. It records aggregate pageviews, referrers and coarse browser/device/country summaries, plus a small fixed set of anonymous action counts (session starts/completions by kind, programme sessions done, set/circuit/meal/check-in saves, install clicks/dismissals). No cookies, no persistent identifiers, no cross-site profiles, and no access to your sets, meals or check-ins. Localhost and preview hosts are not counted.

  • Google Fonts — fonts.googleapis.com, fonts.gstatic.com

    Serves the Inter typeface (hub, Pulse, Car Wash demo) and Barlow Condensed for Pulse's display type. Bible Tracker uses system fonts only.

  • unpkg.com — icon script

    A CDN that delivers the Lucide icon library used by the hub page. This privacy page deliberately does not load it.

  • Supabase — Pulse cloud sync, About Time outings and Done rooms

    Pulse: only contacted if you sign in and turn sync on; your email address and the records you choose to sync are stored in Pulse's Supabase project, protected by row-level security. About Time: contacted when you start or join an outing, so the people in that outing can see each other's battery and readiness; it uses an anonymous session with no email or password. Done: contacted when you open or join a room, so the players can see the round and who has finished their turn; it also uses an anonymous session with no email or password. All three apps keep their data in the same Supabase project, in separate tables protected by row-level security.

  • Browser push service — Apple, Google or Mozilla

    Only if you turn on alerts in About Time or Done. Your browser gives the app a push subscription (an endpoint and two public keys), which is stored so a notification can be delivered when someone in your outing is ready to go, or when everyone in your game room has finished a round. The push itself is routed by your browser's own push service, under that provider's privacy policy. Turning alerts off or clearing site data removes the subscription.

  • Bible.com

    Only if you follow a “Read on Bible.com” link in Bible Tracker. That is a normal outbound link: you leave this site, and the destination's own policy applies.

  • GitHub.com

    Only if you follow a profile or source-code link.

I do not operate Google Fonts, unpkg or GitHub, and I receive no data back from them. GoatCounter is the only analytics service, and it is deliberately cookieless and aggregate. These services appear here because a request to their servers reveals your IP address to them, under their own privacy policies.

What this site does not do

  • — No personal analytics, telemetry, or cross-site tracking.
  • — No advertising, no ad trackers, no third-party pixels.
  • — No cookies, and no fingerprinting.
  • — No accounts, passwords, or email addresses by default. Pulse's optional sync is the only sign-in, and it is passwordless; About Time and Done use an anonymous session with no email at all.
  • — No data sold or shared with anyone. The only analytics is the cookieless aggregate pageview described above.
  • — No personal data stored on a server unless you choose to use Pulse sync, join an About Time outing or join a Done room.

Measurement

The hub and Pulse load GoatCounter only on changelinglabs.com. It is a cookieless, open-source analytics service that records aggregate pageviews, referrers and coarse browser/device/country summaries. It also counts a small fixed set of anonymous actions — session starts/completions by kind, programme sessions done, set/circuit/meal/check-in saves, and install clicks/dismissals. It does not set cookies, create a persistent ID, build a cross-site profile, or receive your sets, meals or check-ins. Localhost and preview hosts are excluded. The purpose is only to know whether pages are being found and which parts of the flow are used.

Your data, your control

By default your app data is not transmitted, so there is nothing for me to hand over, delete, or leak on your behalf. The data the apps hold is only in your browser, on your device: export it for a backup, or clear the site's data to remove it entirely. Every app can export a JSON backup, so do that before clearing anything. If you use Pulse's optional sync, signed-in devices share a copy through Supabase; turning sync off stops further copies, and clearing site data does not by itself delete records already synced. In About Time, leaving an outing deletes your row from the server (and the outing itself once the last person leaves); likewise, leaving a Done room deletes your player row, and the room once the last player leaves. Turning alerts off or clearing site data removes the push subscription. Bible Tracker additionally detects when browser storage is unavailable — in a private window, for instance — and tells you, rather than appearing to save your progress.

Children

No personal information is collected from anyone, including children under 13. There is no account to create and no form that sends data anywhere by default. The exceptions are all chosen by an adult: Pulse's optional cloud sync, which uses an email address for passwordless sign-in; About Time, which sends the display name and emoji you type for an outing to the other people who join that same code; and Done, which sends the display name, emoji, round and done state for a game room to the other players who join that same code. Nothing else is collected.
