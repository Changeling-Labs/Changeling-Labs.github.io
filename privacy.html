Privacy Policy

Last updated 7 November 2026 · covers changelinglabs.com and the apps hosted under it.

The short version

  • — No accounts, no tracking, and no cookies by default.
  • — Apps keep your data in your own browser. Nothing leaves the device unless you turn on Pulse's optional cloud sync.
  • — Pulse sync is opt-in, uses a passwordless email sign-in, and stores only your own records.
  • — No analytics, no advertising, and no server-side database unless you enable that sync.

What this covers

The hub at changelinglabs.com and the applications linked from it: Pulse (/pulse/), Bible Tracker (/bible-tracker/) and the Car Wash demo (/car-wash/). Each one is open source in its own public repository, so every claim below can be checked against the code rather than taken on trust.

What is stored, and where

The hub page stores nothing: no cookies, no identifiers, no local storage — it is static HTML and CSS. The applications that hold progress keep it in your browser's own storage, which never leaves your device and is not visible to this site or to anyone else.

App What it keeps Where
Pulse Logged workouts, exercises, fuel, recovery and preferences IndexedDB; Supabase only if you enable cloud sync
Bible Tracker Reading progress, read history, notes, stars localStorage
Car Wash demo Demonstration member records (synthetic, not real people) IndexedDB

Browser storage belongs to whoever served the page, so clearing site data for this site deletes it permanently. Each app has an Export button for a portable JSON backup; use it before clearing anything. Note too that the storage is scoped to the address you opened — the same app served from a different address (a local file, a local server, or the published site) has its own separate store, and those stores do not merge automatically. Pulse's opt-in cloud sync is the exception: signing in on two devices lets them share one history.

Third parties your browser talks to

Loading any web page means the servers hosting it and its assets see your IP address and standard request headers. This site is no exception, so here is the complete list:

  • GitHub Pages — hosting

    Serves every page here, so GitHub necessarily sees the requests and keeps whatever logs its own policy allows. This site keeps no logs of its own.

  • Google Fonts — fonts.googleapis.com, fonts.gstatic.com

    Serves the Inter typeface (hub, Pulse, Car Wash demo) and Barlow Condensed for Pulse's display type. Bible Tracker uses system fonts only.

  • unpkg.com — icon script

    A CDN that delivers the Lucide icon library used by the hub page. This privacy page deliberately does not load it.

  • Supabase — optional Pulse cloud sync

    Only contacted if you sign in to Pulse and turn sync on. Your email address and the records you choose to sync are stored in Pulse's Supabase project, protected by row-level security. Signed out, no request is made.

  • Bible.com

    Only if you follow a “Read on Bible.com” link in Bible Tracker. That is a normal outbound link: you leave this site, and the destination's own policy applies.

  • GitHub.com

    Only if you follow a profile or source-code link.

I do not operate Google Fonts, unpkg or GitHub, receive no data back from them, and use none of them for analytics. They appear here only because a request to their servers reveals your IP address to them, under their own privacy policies.

What this site does not do

  • — No analytics, telemetry, or usage reporting of any kind.
  • — No advertising, no trackers, no third-party pixels.
  • — No cookies, and no fingerprinting.
  • — No accounts, passwords, or email addresses by default. Pulse's optional sync is the only sign-in, and it is passwordless.
  • — No data sold or shared with anyone. There is no advertising or analytics to fund.
  • — No personal data stored on a server unless you choose to enable Pulse sync.

Your data, your control

By default nothing is transmitted, so there is nothing for me to hand over, delete, or leak on your behalf. The data the apps hold is only in your browser, on your device: export it for a backup, or clear the site's data to remove it entirely. Every app can export a JSON backup, so do that before clearing anything. If you use Pulse's optional sync, signed-in devices share a copy through Supabase; turning sync off stops further copies, and clearing site data does not by itself delete records already synced. Bible Tracker additionally detects when browser storage is unavailable — in a private window, for instance — and tells you, rather than appearing to save your progress.

Children

No personal information is collected from anyone, including children under 13. There is no account to create and no form that sends data anywhere by default. The one exception is Pulse's optional cloud sync, which uses an email address for passwordless sign-in; it is off unless an adult chooses to enable it.

Changes to this policy

If a future feature changes any of this, this page will say so plainly and the date at the top will change. The full history of this page is public in the repository, so anything that changed, and when, is visible.
